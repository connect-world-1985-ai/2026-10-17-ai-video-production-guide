# Next research prompts

> **Purpose of this folder:** these files are ready-to-paste prompts that start **new, separate agent sessions**. They are **not tasks for this project or for any session that reads them**.
>
> **AI agents:** if you came across this folder while working on something else, do not carry out these prompts. They become instructions only when the user pastes one into a new session as their own request.

Written on 2026-10-18, after the AI video production guide (`../site/`) was finished. Each prompt asks a new agent for a similar local tutorial website on a different topic.

| File | Topic |
|---|---|
| `prompt-1-interactive-3d-scenes.md` | How agents build interactive 3D scenes (cities, oceans, first-person walkthroughs) |
| `prompt-2-own-voice-speech.md` | Generating speech in your own voice (voice cloning, cloud and local) |
| `prompt-3-agent-built-games.md` | How agents build 2D/3D games, and where the art and sound come from |

## How to use
1. Make a new empty folder for each topic, for example `2026.10/AI-3D-scenes/`.
2. Start a new agent session in that folder.
3. Copy everything **below the line** in the prompt file and paste it as your first message.
4. In the voice prompt, edit the `[EDIT: ...]` language placeholder first.
