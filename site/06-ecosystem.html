How to read popularity numbers

GitHub stars measure developer interest, not production use; leaderboard Elo scores measure human preference on short prompts, not usefulness in a pipeline; and the two leading video leaderboards disagreed on #1 on the same day (Artificial Analysis: Wan 3.0; LLM-Stats: Kling v3). Commercial products publish no comparable usage data. So this page groups tools by evidence instead of forcing a single ranking. Inference

Three distinctions that prevent bad tool choices

Model ≠ product

"Kling 3.0" is a model; the Kling app, the Kling API, Runway's API, fal and Adobe Firefly are five different products that serve it — with different prices, limits and terms.

Developer tool ≠ end-user app

A popular consumer app (CapCut, Midjourney, Suno) can be unusable for an agent: no official API, terms that forbid automation.

Agent fit ≠ quality

FFmpeg has perfect agent fit and makes nothing beautiful by itself; Midjourney makes beautiful images and has no API. You need both kinds.

Why certain tools became popular

  • FFmpeg — it is the only tool that reads and writes essentially every format, so everything else wraps it. Agents inherit that universality. Practice
  • Remotion — it turned video into a React app, so web developers (and therefore LLMs trained on huge amounts of React) could make video with skills they already have; deterministic frame rendering makes it reviewable. Inference
  • HyperFrames — launched in 2026 explicitly "for agents": plain HTML instead of a framework, bundled skills, lint/preview/render commands an agent can call. Its very fast star growth (~65.7k in seven months) shows how much demand exists for agent-native video tooling. Verified numbers / Inference interpretation
  • Manim — a famous YouTube channel's tool made public; equations and geometry look crisp and correct. Practice
  • ComfyUI — node graphs made complex open-model pipelines shareable as JSON files; it then added paid API nodes for closed models, becoming a hub for both. Practice
  • Blender — free, complete, and fully scriptable in Python; the only pro-grade 3D suite an agent can install and drive without licence friction. Practice
  • ElevenLabs — voice quality plus a developer-friendly API arrived early, and it expanded to dubbing, music, SFX and transcription. Practice
  • Closed video models — quality jumps make the top spot change every few months; adoption follows the leaderboard and price, not loyalty. Expect churn. Inference
