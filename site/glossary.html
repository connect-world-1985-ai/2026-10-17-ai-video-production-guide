Reference

Glossary

Terms from video production, graphics, audio and generative AI, in plain language.

TermMeaning
Alpha channelPer-pixel transparency stored with an image or video, so a layer can sit over another.
ASRAutomatic speech recognition — turning speech into text, ideally with word timestamps.
Aspect ratioWidth:height of the frame — 16:9 (YouTube), 9:16 (Shorts/Reels/TikTok), 1:1.
B-rollSupporting footage shown while narration or interview audio continues.
BitrateData per second in an encoded video; higher = more quality and larger files.
C2PA / Content CredentialsOpen standard for signed provenance metadata describing how a media file was made and edited.
Classifier-free guidanceDiffusion trick that strengthens prompt adherence by contrasting predictions with and without the prompt.
CodecCompression method for video/audio (H.264, H.265, AV1, ProRes, AAC, Opus).
Colour grading / LUTGiving footage a look; a LUT (look-up table) is a reusable colour transform.
CompositingCombining layers (footage, renders, text) into one image per frame.
ContainerFile format holding streams (MP4, MOV, MKV, WebM).
ControlNetMethod to condition image/video generation on structure (pose, depth, edges).
Cue pointA time at which something must happen (animation start, SFX), often tied to a narration word.
Diffusion modelGenerative model that creates data by iteratively removing noise.
DiT (Diffusion Transformer)Transformer used as the denoiser in diffusion; the dominant video-model backbone.
DuckingAutomatically lowering music when speech is present (side-chain compression).
EDL / FCPXML / OTIOTimeline interchange formats: Edit Decision List, Final Cut XML, OpenTimelineIO.
EasingThe speed curve of an animation between keyframes (linear, ease-in-out, spring).
F-curveBlender's name for an animation curve of a property over time.
First/last-frame conditioningGiving a video model the exact start (and end) image so it generates the motion between.
Flow matching / rectified flowTraining method that learns to move noise straight toward data; fewer sampling steps than classic diffusion.
FoleyEveryday sound effects synced to on-screen action (footsteps, clunks).
Forced alignmentGiven audio and its exact text, compute when each word/phoneme is spoken.
fpsFrames per second (24 cinematic, 25 PAL, 30 web, 60 smooth UI).
Frame interpolationSynthesising in-between frames to raise fps or create slow motion.
Gaussian splatting / NeRFWays to reconstruct a real 3D scene from photos and render new views.
Headless renderingRendering without a visible UI, from a script or command line — what agents need.
I2V / T2V / V2VImage-to-video, text-to-video, video-to-video generation.
Keyframe(Animation) a stored value at a point in time; (generation) a designed still that anchors a shot.
Latent spaceCompressed representation where generative models work; decoded back to pixels.
LoRASmall fine-tuned adapter that teaches a model a character, product or style.
Lower thirdText graphic in the lower part of the frame (name, title, label).
LUFS / LKFSLoudness units (ITU-R BS.1770); targets like −23 (EBU R128) or about −14 (online).
Matte / maskDefines which pixels an effect or layer affects; AI segmentation creates them automatically.
MCPModel Context Protocol — a standard way to expose tools to AI agents.
MocapMotion capture — recording real movement to drive a 3D character.
NLENon-linear editor (Premiere, Resolve, Final Cut, Kdenlive).
Path tracingPhysically based rendering by simulating many light paths per pixel.
PBRPhysically based rendering materials (base colour, roughness, metallic).
RasterisationFast GPU rendering by projecting triangles to the screen.
Rec.709Standard colour space for HD/SDR video.
Reference-to-videoGeneration conditioned on reference images (and sometimes videos/audio) to keep identity.
Scene graphTree of objects with transforms that describes a 2D/3D scene.
SeedNumber that fixes the initial noise of a generation; same seed + same model → similar output.
Shot listPer-shot plan: content, duration, camera, technology, assets, audio cues.
Spacetime patchesSmall 3D blocks of a video latent used as transformer tokens.
SRT / VTT / ASSSubtitle formats (simple, web, styled).
SSMLMarkup to control TTS (pauses, emphasis, pronunciation).
StoryboardSequence of frames showing what each shot looks like.
SynthIDGoogle's invisible watermark for AI-generated media.
TimelineTracks of clips placed in time; the data structure behind any edit.
True peak (dBTP)Peak level including inter-sample peaks; commonly kept ≤ −1 dBTP.
TTSText-to-speech.
VAEVariational autoencoder; compresses images/video into latents and decodes them.
VisemeVisual mouth shape corresponding to a speech sound; used for lip-sync.
VLMVision-language model — an LLM that can read images (and sometimes video).
World modelModel that generates an explorable, action-responsive environment frame by frame.
