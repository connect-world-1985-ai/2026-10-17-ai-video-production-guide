怎么读流行度数字

GitHub 星标衡量的是开发者的兴趣，不是生产用量；排行榜 Elo 分数衡量的是人对短提示的偏好，不是在一条流水线里好不好用；而且当天两个主要的视频排行榜对第一名意见不一致（Artificial Analysis：Wan 3.0；LLM-Stats：Kling v3）。商业产品没有公布可比较的用量数据。所以这一页按证据把工具分组，而不是硬排一个总名次。推断

三个区分，免得选错工具

模型 ≠ 产品

“Kling 3.0”是一个模型；Kling 应用、Kling API、Runway 的 API、fal 和 Adobe Firefly 是五个不同的产品，都在提供它——价格、限额和条款各不相同。

开发者工具 ≠ 终端用户应用

一个很流行的消费级应用（CapCut、Midjourney、Suno）对代理可能完全没法用：没有官方 API，条款禁止自动化。

代理适配 ≠ 质量

FFmpeg 的代理适配满分，自己却做不出好看的东西；Midjourney 能做出好看的图，却没有 API。两种你都需要。

为什么有些工具变得流行

  • FFmpeg — 它是唯一几乎什么格式都能读、都能写的工具，所以别的东西都包着它。代理继承了这种通用性。实践
  • Remotion — 它把视频变成一个 React 应用，于是网页开发者（以及因此在大量 React 上训练出来的大语言模型）可以用已有的本事做视频；确定性的逐帧渲染让结果可以复查。推断
  • HyperFrames — 2026 年上线时就明确说“给代理用”：用普通 HTML 而不是一套框架，打包好的技能，代理能调用的检查/预览/渲染命令。星标涨得非常快（七个月大约 65.7k），说明对代理原生视频工具的需求有多大。已核对的数字 / 推断的解读
  • Manim — 一个著名 YouTube 频道的工具公开了；公式和几何看起来清晰、正确。实践
  • ComfyUI — 节点图让复杂的开源模型流水线可以当成 JSON 文件分享；后来又加了调用封闭模型的付费 API 节点，于是成了两边的枢纽。实践
  • Blender — 免费、完整，而且能用 Python 完全写脚本；唯一一套代理能装上、能驱动、又没有许可摩擦的专业级三维套件。实践
  • ElevenLabs — 语音质量加上对开发者友好的 API 来得早，后来又扩到配音、音乐、音效和转写。实践
  • 封闭视频模型 — 质量跳跃让头名每隔几个月就换；采用跟着排行榜和价格走，不跟着忠诚走。要预料到更替。推断
