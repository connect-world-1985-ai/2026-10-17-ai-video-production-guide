术语表

视频制作、图形、音频和生成式人工智能里的词，用白话说明。中文名后面括号里是原文，方便你去查文档。

术语含义
透明通道（Alpha channel）随图像或视频保存的逐像素透明度，让一层可以叠在另一层上。
自动语音识别（ASR）把语音变成文字，最好还带每个词的时间戳。
宽高比（Aspect ratio）画面的宽比高：16:9（YouTube）、9:16（Shorts、Reels、TikTok）、1:1。
空镜（B-roll）口播或采访声音继续时，切出来的辅助画面。
码率（Bitrate）编码后每秒的数据量；更高通常更清晰，文件也更大。
C2PA / 内容凭证（Content Credentials）一套开放标准，用签名过的来源元数据说明媒体是怎么做出来、怎么改过的。
无分类器引导（Classifier-free guidance）扩散模型的手法：把“有提示”和“没有提示”的预测对照，加强对提示的服从。
编解码器（Codec）视频或音频的压缩方法（H.264、H.265、AV1、ProRes、AAC、Opus）。
调色 / 查找表（Colour grading / LUT）给画面一种观感；查找表是一份可复用的色彩变换。
合成（Compositing）把多层（实拍、渲染、文字）合成每一帧上的一幅图。
容器（Container）装着多条流的文件格式（MP4、MOV、MKV、WebM）。
ControlNet用结构（姿态、深度、边缘）来约束图像或视频生成的方法。
提示点（Cue point）某件事必须发生的时刻（动画开始、音效响起），常常绑在口播的某个词上。
扩散模型（Diffusion model）通过一步步去掉噪声来生成数据的模型。
扩散 Transformer（DiT）在扩散里当去噪器的 Transformer；当前视频模型的主流骨架。
压低（Ducking）有人说话时自动把音乐压下去（侧链压缩）。
EDL / FCPXML / OTIO时间线交换格式：剪辑决策表、Final Cut 的 XML、OpenTimelineIO。
缓动（Easing）两个关键帧之间动画的速度曲线（线性、缓入缓出、弹簧）。
函数曲线（F-curve）Blender 对“某个属性随时间变化的动画曲线”的叫法。
首帧 / 末帧条件（First/last-frame conditioning）把确切的开始图（以及结束图）交给视频模型，让它生成中间的运动。
流匹配 / 矫正流（Flow matching / rectified flow）一种训练方法，学习把噪声沿直线挪向数据；采样步数比经典扩散少。
拟音（Foley）对上画面动作的日常音效（脚步、碰撞）。
强制对齐（Forced alignment）给定音频和它的确切文字，算出每个词或音素是何时说出来的。
帧率（fps）每秒帧数（电影 24，PAL 25，网页 30，顺滑界面 60）。
帧插值（Frame interpolation）合成中间帧，用来提高帧率或做慢动作。
高斯泼溅 / NeRF从照片重建真实三维场景、再渲染新视角的方法。
无界面渲染（Headless rendering）没有可见界面，从脚本或命令行渲染——代理需要的就是这个。
图生视频 / 文生视频 / 视频生视频（I2V / T2V / V2V）从图像、文字或另一段视频生成视频。
关键帧（Keyframe）动画里：某一时刻存下的值。生成里：用来锚定一个镜头的设计静帧。
潜空间（Latent space）生成模型工作的压缩表示，再解码回像素。
LoRA一小块微调适配器，教模型一个角色、一件产品或一种风格。
下三分之一（Lower third）画面下方的文字图形（姓名、头衔、标签）。
LUFS / LKFS响度单位（ITU-R BS.1770）；目标例如 −23（EBU R128）或大约 −14（网络）。
遮罩（Matte / mask）规定效果或图层作用在哪些像素上；人工智能分割可以自动做出遮罩。
MCP模型上下文协议（Model Context Protocol）——把工具暴露给人工智能代理的一种标准方式。
动作捕捉（Mocap）记录真实动作，用来驱动三维角色。
非线性剪辑（NLE）非线性剪辑软件（Premiere、Resolve、Final Cut、Kdenlive）。
路径追踪（Path tracing）通过模拟每个像素上大量光线路径来做的基于物理的渲染。
基于物理的渲染（PBR）用基础色、粗糙度、金属度等描述材质的渲染方式。
光栅化（Rasterisation）把三角形投影到屏幕上的快速图形处理器渲染。
Rec.709高清、标准动态范围视频的标准色彩空间。
参考生视频（Reference-to-video）用参考图（有时还有参考视频或音频）约束生成，以保住身份。
场景图（Scene graph）一棵带变换的物体树，用来描述二维或三维场景。
种子（Seed）固定一次生成初始噪声的数字；同样的种子加同样的模型，输出相近。
镜头表（Shot list）逐镜头的计划：内容、时长、摄像机、技术、资产、声音提示。
时空块（Spacetime patches）视频潜表示里的小三维块，当作 Transformer 的词元。
SRT / VTT / ASS字幕格式（简单、网页、带样式）。
SSML控制语音合成的标记（停顿、重音、读音）。
分镜（Storyboard）一串画面，展示每个镜头长什么样。
SynthIDGoogle 给人工智能生成媒体加的不可见水印。
时间线（Timeline）按时间摆放的多条片段轨道；任何一次剪辑背后的数据结构。
真峰值（True peak，dBTP）包含采样间峰值的峰值电平；通常压在 −1 dBTP 及以下。
语音合成（TTS）文字转语音。
变分自编码器（VAE）把图像或视频压进潜空间、再解码回来的模型。
视素（Viseme）对应一个语音的嘴型；用于口型同步。
视觉语言模型（VLM）能读图像（有时也能读视频）的大语言模型。
世界模型（World model）一帧一帧生成可探索、会对动作作出反应的环境的模型。
