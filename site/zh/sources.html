来源与方法

这份指南是怎么研究的、说法怎么标注、每一条来源在哪里找。

方法

  1. 独立发现（2026-10-17）：六路并行研究覆盖了神经视频；图像、数字人与增强；程序化图形与剪辑；音频；代理工作流与视频质检；法律与来源。每一路产出一份带来源的事实表，带查阅日期，并有明确的“分歧与不确定”一节。
  2. 原始来源优先：官方文档、价格页、仓库（星标和许可于 2026-10-17 从 GitHub API 读取）、论文、许可文件。二手来源（新闻、律所笔记、聚合器）用在没有原始页面可及的地方，并照此标注。
  3. 作者本人核对最要紧的说法，直接对照原始来源：Gemini API 视频价格；Artificial Analysis 文生视频排行榜；Wan 2.1 的架构数字；Sora 关停；DaVinci Resolve 21.1 的脚本改动；HunyuanVideo 的地域条款；代理工具的 GitHub 统计；video-use 的技能文件。
  4. 不编造数字：每一个价格、星标数和基准都有来源；来源冲突的地方，冲突被写出来。

证据标签

标签含义
已核对对照过原始来源（文档、仓库、论文、许可、官方公告），或由若干独立的可靠出处确认。
实践有证据支持的行业做法，或被广泛记录的行为。
推断作者的技术分析或综合——经过推理，不是作为事实来源引用的。
未核实有人报告或在营销，但没有独立确认；来源互相冲突。
实验新兴能力：研究或演示级别。

这项研究已知的局限

  • 排行榜没有快照日期，每周都变；名次读于 2026-10-17。
  • 若干价格来自聚合器或转售方（已标注）；厂商页面有时渲染失败。
  • GitHub 星标衡量的是兴趣，不是生产使用；镜像仓库（Blender、FFmpeg）会低估流行程度。
  • 德国人格权法没有用原始来源研究过。
  • 视频产品内部的商业“代理模式”只根据二手材料评估。
  • 没有亲手跑基准；所有质量说法来自已发表的评测或文档。
