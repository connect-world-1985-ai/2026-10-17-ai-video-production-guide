Local, cloud and hybrid production

Where should each step run? There is no single answer: deterministic work is cheap and private locally, while state-of-the-art generative models are mostly only reachable as cloud APIs. Most practical setups end up hybrid.

Architecture A — local production

ConcernWhat to expect
HardwareCode-driven 2D, FFmpeg, ASR and many TTS models run on an ordinary developer machine. Blender renders benefit greatly from a modern NVIDIA GPU. Privacy & controlBest: nothing leaves the machine; models never change underneath you; seeds reproduce.

Architecture B — cloud production

The universal async job pattern

All major generation APIs follow this shape: fal's queue API (submit → status polling, streaming, or a webhook, with cancellation), Replicate predictions (poll or webhook, optional synchronous wait), Google's long-running operations for Veo (poll until done; generated videos are stored for only 2 days). Verified (fal docs, Replicate docs, Gemini Veo docs)

ConcernWhat to expect
APIs & SDKsVendor APIs (Google, Runway, MiniMax, Kling, ElevenLabs…), aggregators (fal, Replicate, Runway as reseller, ComfyUI partner nodes), some MCP servers.
ReliabilityJobs fail, time out, or get blocked by content filters (some platforms still bill blocked outputs). Generation latency for Veo ranges from ~11 s to ~6 min at peak per Google docs. Verified
Rate limits & quotasPer-key concurrency limits; tiered quotas; plan for a queue in your orchestrator.
Access restrictionsRegional: e.g. Gemini Omni video editing of uploads not available in the EEA, Switzerland or UK; Veo person-generation settings restricted in the EU/UK/CH/MENA. Verified (Gemini docs, 2026-10-17). Relevant if you work from Germany.
Change riskModels and endpoints are deprecated quickly: Sora shut down in 2026; the original Nano Banana image model was scheduled to shut down 2026-10-02; aggregator endpoints carry deprecation notices. Verified
CostPer second of generated video: roughly $0.05–0.70 depending on model, tier and resolution (Oct 2026). Voice: cents per minute. Verified ranges from vendor/aggregator price pages
Quality & scaleBest available models; parallel jobs; no hardware to manage.

Inference from the facts above.

An adapter layer is the cheapest insurance

Wrap every external generator behind one internal interface (generate_clip(spec) → file + metadata). When a provider changes prices, deprecates a model, or shuts down — as happened with Sora — you change one adapter, not your pipeline. Record provider, model, version and cost in the manifest for every call. Inference

Total cost of production — the honest version

  1. Your time reviewing and directing (largest for quality work).
  2. Iteration multiplier: generative shots typically need several attempts; budget 2–4× the final seconds. Practice
  3. Agent tokens: planning, code, and especially visual QA (images are token-heavy).
  4. Generation APIs: per second/character/image.
  5. Licences: stock footage, music, fonts, software (e.g. Remotion company licence, Resolve Studio).
  6. Compute and maintenance: local GPU, cloud rendering, storage.
