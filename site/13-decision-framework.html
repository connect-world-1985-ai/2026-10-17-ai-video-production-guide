Decision framework: choosing the method for each shot

The core skill of an AI video director — human or agent — is routing each shot to the right machine. This page gives the rules, a trade-off matrix, an interactive helper, and three reference stacks.

The rules behind it

QuestionRule of thumb
Generative video or code-driven animation?If anything in the shot must be exactly right (text, data, mechanism, brand), use code/rendering. If it only needs to be plausible and beautiful, generative video is cheaper. If both: render the exact parts, generate the rest, composite (D4), or restyle a render (D2).
When is 3D rendering preferable?Objects must stay identical across many shots; camera must move precisely; mechanisms or physics must be correct; you need many variations of the same scene.
When to generate a still first?Almost always before image-to-video: stills are cheap to generate and inspect, fix composition and identity, and give I2V a precise starting point.
External API or local inference?API for best quality and no hardware; local for privacy, cost at high volume, deterministic re-runs, and licence-permitting open models. Check open-model licences for your region (some exclude the EU).
Generate audio separately?Yes for narrated, multi-shot videos (consistent voice, exact words, stems, captions). Native audio is fine for short standalone clips and ambience.
Use a professional editing application?For a human finishing pass (grade, mix, client review) — via a timeline hand-off (FCPXML/OTIO). Not as the agent's main engine unless it has a stable scripting API (Resolve Studio).
What is easy to automate precisely?Rendering code, assembly, timing from timestamps, captions, loudness, encoding, metadata checks, partial rebuilds.
What stays probabilistic?Any generative output (video, image, voice prosody, music), AI judgement of quality, and the agent's own creative choices.
How to combine for professional results?Deterministic backbone (script, timeline, renders, mix) + generative inserts with references + one look (grade, typography, sound) + human checkpoints.

Reference stacks: beginner → advanced

Illustrative architectures for a Windows-based engineer using a coding agent — not universal solutions. Tool names are examples of a class; see the explorer for alternatives.

Goal: narrated explainers and product videos, mostly code-driven

  • Agent: Claude Code / Codex / Cursor with a video skill pack (Remotion skills or HyperFrames skills; or Manim).
  • Visuals: one code framework (React/HTML-based or Manim). A few generated b-roll clips via a single API (e.g. a "Fast/Lite" tier of a major model).
  • Voice: one cloud TTS (or a local open model if licence fits); word timings from the vendor or from faster-whisper.
  • Music: licensed library track or a music API with commercial terms.
  • Assembly: the framework's renderer + FFmpeg; captions from timestamps; two-pass loudness.
  • QA: ffprobe, loudness, ASR-vs-script, agent inspects stills at cue points; you watch the result.
  • Cost profile: mostly agent tokens + cents of TTS + a few dollars of generated b-roll.

Goal: documentary-style and marketing videos with mixed technologies

  • Everything in Beginner, plus:
  • Keyframes with an image model using reference images; I2V via an aggregator (fal/Replicate/Runway API) behind your own adapter.
  • 3D: Blender driven headlessly with Python (optionally via an MCP server).
  • Project as a build: shotlist.json + timeline.json + DAG with input hashing; job table for async generation; cost ledger.
  • QA stack: detectors + OCR + frames-to-vision-model + one whole-video pass with a video-capable model + human gates.
  • Provenance: asset manifest with licences; sign final export with C2PA.

Goal: cinematic, character-driven or high-volume production

  • Everything in Intermediate, plus:
  • Local/rented GPU running licence-compatible open models in ComfyUI (e.g. Wan 2.2 Apache-2.0, LTX-2.5 under its revenue threshold) for cheap iterations, LoRAs for characters/products, control signals (depth/pose) for D2 restyles.
  • Hybrid CG + AI: 3D blockouts with exact cameras → video-to-video restyle; avatars/lip-sync with consent records.
  • Director + subagents: parallel shot builders and specialised critics (continuity, legibility, pacing, brand) under one coordinator.
  • Finishing hand-off to a pro NLE (OTIO/FCPXML) for grade and mix; multi-format deliverables; localisation.
  • Operations: containerised toolchain, pinned versions, spend limits per key, monitoring of model deprecations.
