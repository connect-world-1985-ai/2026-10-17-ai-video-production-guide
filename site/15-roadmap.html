Learning roadmap and next steps

How to go from "I understand the landscape" to "I can design and supervise an agent video pipeline", in small hands-on stages — plus the open questions worth investigating together.

Learning roadmap (Deliverable I)

Each stage has one concrete outcome. Stages build on each other; you can stop after any stage with a useful capability. Inference

  1. Vocabulary & anatomy of a video — frames, fps, codecs, timelines, tracks, LUFS, captions. Outcome: take a video apart with ffprobe and FFmpeg (extract frames, audio, measure loudness). Pages 5, 4.
  2. Code-driven video with an agent — have your coding agent build a 30-second animated explainer with one code framework (Remotion or HyperFrames for web skills; Manim for math). Outcome: you understand frame-based rendering and how the agent iterates on code. Page 3.
  3. Narration-driven timing — add TTS narration, extract word timestamps, drive cue points and captions from them, mix with a music bed at a loudness target. Outcome: the "audio-first" pipeline. Page 4.
  4. Self-inspection loop — make the agent sample frames at cue points, run ASR-vs-script and loudness checks, write a QA report and fix issues. Outcome: you see what agents catch and miss. Page 7.
  5. Generative inserts — generate keyframes with references, animate 2–3 with image-to-video via one API, composite exact overlays on top, grade to match. Outcome: you feel the cost/variance of generative shots. Page 2.
  6. Project as a build — shot list + timeline as data, input hashing, job table, cost ledger, partial re-renders. Outcome: a resumable, reproducible pipeline. Pages 8, 12.
  7. 3D — have the agent build and render one Blender shot headlessly (simple model, camera move, lighting from an HDRI). Outcome: where 3D beats generation, and where agents struggle.
  8. The full worked example — produce a 2-minute documentary end to end with three human checkpoints. Outcome: your own reference pipeline and honest cost data.
  9. Advanced options — local open models in ComfyUI, LoRAs, CG→video restyle, critic subagents, provenance signing, NLE hand-off.

Recommended next discussions

Based on what the research revealed, these five directions give the most leverage:

1 · Design your reference pipeline

Concrete architecture for your first video category on Windows: tool choices, project layout, build graph, adapters, budgets — the beginner→intermediate stack made specific.

2 · Agent self-QA deep dive

Build and measure the inspection stack: what to sample, what to measure, how to turn critiques into diffs, and stopping rules. This is where agents gain or lose most.

3 · Code-driven video frameworks compared hands-on

Remotion vs HyperFrames vs Manim for agent use: licences, determinism, skills, Windows behaviour — with a tiny prototype in each.

4 · Generative shot craft

Keyframe-first workflows, references, I2V chaining, consistency, and cost control across 3–4 current models.

5 · Rights, provenance and compliance by design

Asset manifest, licence register, consent records, Art. 50 labelling and C2PA signing as automated pipeline steps.
